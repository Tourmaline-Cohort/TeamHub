# TeamHub

Follow the Instructions below

1. Open your Tourmaline folder on VS Code
1. Open the integrated terminal (Git Bash) on vs code
1. Using the command below, clone the project unto your local machine

   ```bash
   git clone https://github.com/Tourmaline-Cohort/TeamHub.git
   ```

1. CD into **TeamHub** folder
1. Create a new branch using the command
    ```bash
    git checkout -b "write the name of the branch here"
    ```
1. Now create a new folder within TeamHub's folder. The name of the folder should same as the project you have been assigned to work on
1. Within your project folder, create a Markdown file name README.md.
1. Write the name of the project you have been assigned to work on.
1. Stage, commit and push to the remote branch. **Take note that you do not need to do git init again as this is a cloned project**

    ```
    git add .
    git commit -m "Initial commit for my assigned lab project"
    git push origin main

    ```
